Quantitative Applications HTML Prototype

Files:
- index.html        Home / Prototype A direction
- documents.html    Marketplace / Prototype E direction
- product.html      Reusable document detail page
- about.html
- contact.html
- styles.css
- script.js

To run locally:
1. Open the folder in VS Code.
2. Either open index.html directly in a browser, or use Live Server.
3. Start with index.html.

Prototype functionality included:
- Responsive layout
- Home document search
- Document marketplace category filters
- Search and sorting
- LocalStorage cart prototype
- Product detail pages through query parameters
- Placeholder checkout
- Placeholder contact form
